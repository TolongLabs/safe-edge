# Rival ideas

The 240 ideas that two AI models gave when we prompted them the way rival students would, on 16 October 2026. We use them to measure which problems are crowded; see [Niche township problems](/docs/research/niche-problems.md#crowding-map). Each run was a fresh session with no web access, given the challenge brief from the official page plus one of four requests. Titles and problem lines are the models' own words, trimmed.
