Safe Edge — Design SystemVolume 01

Statement

A calm system for a serious safety question.

Safe Edge helps a park team find a gap at the water edge, choose the fix that closes every way to the water, and prove the repair passes. The interface is built for a non-technical reader in a hurry.

The design system exists so that urgency never becomes noise. One question per screen. One primary action. State carried by shape as well as colour, so it survives glare, colour blindness and greyscale print.

“A missing fence is serious. The screen states the fact, the consequence and the next step, and never shouts.”

The Solid Surface Rule. Cards, buttons, menus, bars and dialogs have solid fills. Nothing that holds text is transparent.

One action green. Park Plate Green marks the one action that moves the case forward. It is dark enough for white text.

The Shape-Carries-State Rule.

A pass state is never shown by colour alone. Every mark has its own shape, and every badge also carries words. The system survives glare, colour blindness and a greyscale photocopy.

The Calm Alarm Rule.

Red appears only where a safety item is missing, a route is open, or an action is destructive. Warnings with a plan already in motion use Expiring Amber.

04.1 · Honesty in every state

Nothing is “all clear” unless it was seen.

Every screen ships empty, loading and error states, in Light and Dark. An empty screen never implies safe.

INBOX · EMPTY

Retention pond 3 stayed unknown on the last patrol. Nothing is cleared.
Send No evidence to send.
INBOX · LOADING
Loading the last patrol for Elmina.
INBOX · ERROR
The drone feed is offline. Existing evidence stays visible. A walk crew checks at 10:00.
Actions that cannot work stay disabled, with the reason beside them.
Try again Last attempt 09:41.
Empty names the unknown.

“3 spots were not visible” is honest. “All clear” would not be.

Loading keeps the layout.

Skeletons sit in the real rows, with one line that says what is loading.

Error keeps the evidence.

The banner says what failed, what still works and what happens next.
